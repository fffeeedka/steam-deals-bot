# 🎮 steam-deals-bot

Telegram-бот, который присылает в чат **бесплатные новинки Steam** — и умеет расставлять приоритеты: жанры, которые тебе важны, идут первыми со звёздочкой, нелюбимые жанры скрываются.

Каждый чат настраивает всё под себя: бота можно добавить в группу, и у группы будут свои настройки.

## Возможности

- Ловит **новые бесплатные игры** (free-to-play релизы) и **раздачи Free to Keep** (бесплатно навсегда, если забрать сейчас).
- Режимы: только бесплатное / все новинки / скидки от N%.
- Приоритетные жанры (⭐ в карточке), скрытые жанры.
- Понимает, о чём уже писал: повторов не будет.
- Проверяет Steam по расписанию и по команде `/scan`.
- Аккаунт Steam не нужен, ничего не покупается и не добавляется в библиотеку — приходит ссылка, забрать надо самому.

## Быстрый старт

1. **Токен бота.** Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → имя и username → получишь `BOT_TOKEN`.
2. **Зависимости:**

   ```bash
   python -m pip install -r requirements.txt
   ```

3. **Запуск:**

   ```bash
   export BOT_TOKEN="123456:AAA..."    # Windows PowerShell: $env:BOT_TOKEN="123456:AAA..."
   python -m steam_deals_bot
   ```

4. Открой бота в Telegram → `/start`.

Если бот в группе — дай ему право писать сообщения, админ-права не нужны.

## Команды

| Команда | Что делает |
| --- | --- |
| `/start` | подписаться на рассылку |
| `/settings` | показать текущие настройки |
| `/mode free\|new\|deals` | что присылать |
| `/discount 60` | минимальная скидка для режима `deals` |
| `/priority indie,horror` | приоритетные жанры — выше в выдаче и со ⭐ |
| `/block early access` | скрыть жанры |
| `/latest` | последние находки |
| `/scan` | проверить Steam прямо сейчас |
| `/stop` | отключить рассылку |

Режимы:

- `free` — только бесплатное: F2P-релизы и раздачи «бесплатно навсегда»;
- `new` — новинки, которые бесплатны или со скидкой от 40%;
- `deals` — скидки не ниже `/discount`.

## Настройка через переменные окружения

Скопируй `.env.example` в `.env` и заполни (или задай переменные в системе):

| Переменная | По умолчанию | Смысл |
| --- | --- | --- |
| `BOT_TOKEN` | — | токен от BotFather, обязателен |
| `STEAM_CC` | `us` | регион магазина, влияет на валюту и акции |
| `CHECK_INTERVAL_MINUTES` | `15` | период проверки Steam |
| `MAX_PER_RUN` | `5` | сколько сообщений максимум на чат за прогон |
| `NEW_LOOKUP_LIMIT` | `120` | сколько новых appid проверять за прогон |
| `DATA_DIR` | `data` | папка для `bot.db` и кэша каталога |

Бот использует только стандартную библиотеку Python плюс `python-telegram-bot`. `.env` сам не читается — экспортируй переменные или запускай через `docker run --env-file .env`.

## Как работает поиск новинок

У Steam нет публичного «ленты релизов», поэтому бот использует две вещи:

1. **Каталог приложений** (`ISteamApps/GetAppList`) — appid в Steam растут монотонно, поэтому сущности с номером больше последнего увиденного и есть новинки. Бот помнит границу в SQLite и проверяет только новые номера.
2. **Поиск Steam с фильтром «бесплатно + акция»** — им ловятся ограниченные раздачи Free to Keep, которые в каталоге уже есть.

Для каждого кандидата запрашивается `appdetails`: тип, цена, жанры, дата выхода. Игра считается раздачей, если `is_free == false`, `price_overview.initial > 0` и `final == 0`.

## Если `api.telegram.org` заблокирован

Симптом: `telegram.error.TimedOut` при запуске. Проверить одной командой:

```bash
python -c "import urllib.request;print(urllib.request.urlopen('https://api.telegram.org/',timeout=15).status)"
```

Таймаут означает блокировку на уровне сети — ни код, ни токен тут не виноваты. Варианты:

1. **VPN в режиме глобального туннеля (TUN).** Браузерный режим не поможет: Python ходит мимо него. После включения перезапусти бота в новом окне терминала.
2. **Прокси.** `python-telegram-bot` читает переменные окружения сам:

   ```bash
   export HTTPS_PROXY="http://127.0.0.1:1080"
   export HTTP_PROXY="http://127.0.0.1:1080"
   python -m steam_deals_bot
   ```

3. **Деплой на хостинг без блокировки** — единственный вариант для бота, который должен работать круглосуточно.

Steam API при этом обычно доступен и без VPN — блокируется именно Telegram.

## Запуск 24/7

### Docker

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
CMD ["python", "-m", "steam_deals_bot"]
```

```bash
docker build -t steam-deals-bot .
docker run -d --restart unless-stopped --env-file .env -v "$(pwd)/data:/app/data" steam-deals-bot
```

### Railway / Fly.io / любой PaaS

1. Запушь репозиторий на GitHub — `Dockerfile` подхватится автоматически.
2. Добавь переменную окружения `BOT_TOKEN` (и при желании `STEAM_CC`).
3. Подключи постоянный диск, смонтированный в `/app/data`, иначе при рестарте потеряются подписки и настройки.

### systemd (Linux)

```ini
[Unit]
Description=steam-deals-bot
After=network-online.target

[Service]
WorkingDirectory=/opt/steam-deals-bot
EnvironmentFile=/opt/steam-deals-bot/.env
ExecStart=/opt/steam-deals-bot/.venv/bin/python -m steam_deals_bot
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

### Windows

Создай задачу в Планировщике с триггером «при входе в систему»: программа `python`, аргументы `-m steam_deals_bot`, рабочая папка — папка проекта. Либо просто держи окно `python -m steam_deals_bot` открытым.

## Ограничения

- Steam ограничивает частоту запросов: за один прогон проверяется `NEW_LOOKUP_LIMIT` кандидатов с паузой ~1 сек. Если Steam начал отвечать 429, уменьши лимит.
- Часть раздач распространяется пакетами и не показывает `price_overview` — такие пропускаются.
- Каталог приложений кэшируется на 7 дней; для совсем свежих релизов он обновится сам.
- Регион `STEAM_CC` влияет на то, какие акции видны.
